Markdown Annotator

Open a Markdown file, highlight passages and comment on them, then copy everything as one review, ready to paste into an AI assistant, a chat or a pull request.

Recent

    1. Select text, press C, type, press Enter.
    2. Press Enter to copy your comments as one review, then paste it where it is needed.
    3. When the file changes on disk, it reloads here in place. Changed blocks are marked; N jumps between them.

    Documents and comments stay in this browser (other local HTML files opened in Chrome can read the same storage). · Shortcuts ?

    Left as the default, these instructions adapt to each review: they name the file or describe pasted text, and mention comments, quotes and line numbers only when the review has them. Edited, they are used as written, with {file} (the file), {count} (what is included) and {lines} (how current the line numbers are) filled in. Leave empty for no instructions.
